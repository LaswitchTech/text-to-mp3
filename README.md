## Description
**Author(s)**: [LaswitchTech](support@laswitchtech.com)

Python Text to MP3 Script to convert text to MP3 files using the Google Text-to-Speech API. This script is designed to be simple and easy to use, allowing you to generate MP3 files from text input quickly.
